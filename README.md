# Stack 3D

🎮 Isometric block stacking game built with pure HTML5, CSS and JavaScript.

## 🎯 About

Stack 3D — это аркадная игра, где нужно ставить блоки друг на друга. 
Чем точнее попадание — тем выше башня. Промахнулся — отрезается лишнее. 
Полностью промахнулся — игра окончена.

Игра работает **полностью офлайн**, в одном HTML-файле. 
Никаких библиотек, никакого интернета, никакой установки.

## 🕹️ How to play

- **Tap / Click / Space** — поставить блок
- **Perfect!** — если попал почти идеально, блок выравнивается и вспыхивает
- **Game Over** — если блок вообще не пересёкся с предыдущим

## ✨ Features

- 🎮 **Три режима**: Classic, Speed, Hard
- 🌍 **Смена языка**: English / Russian
- 🎨 **9 фоновых палитр** + смена по времени
- 🍂 **Осенние листья** в меню
- 💥 **Частицы** при отрезании блоков
- 🔊 **Звуки** через Web Audio (без файлов)
- 🏆 **Рекорды** сохраняются в localStorage
- 📜 **Changelog** с историей обновлений
- 📱 **Адаптивность** под все экраны и вырезы
- 🌐 **Работает офлайн** — один HTML-файл
